# ZanderoDev - Portofolio

Portofolio personal dan repositori kredensial M. Ilham Mufid. Dibangun pakai HTML5 semantik, CSS3 modern, dan JavaScript vanilla tanpa framework berat. Ringan, cepat, responsif di layar HP maupun PC, dan patuh standar aksesibilitas WCAG.

## Fitur Utama

- **Repositori Sertifikat**: Filter kategori dan fitur pencarian real-time buat eksplorasi sertifikat resmi.
- **Mesin Validasi ID**: Cek langsung keaslian nomor registrasi kredensial dengan cepat.
- **Terminal Shell Interaktif**: Eksplorasi data portofolio lewat konsol perintah (`help`, `whoami`, `certs`, `skills`, `verify`).
- **Detail Modal & Arsip PDF**: Pratinjau dokumen lengkap plus tautan verifikasi langsung ke portal penerbit asli.
- **Responsif Lintas Perangkat**: Tampilan rapi dan nyaman diakses dari ponsel layar kecil sampai monitor PC lebar.

## Stack Teknis

- HTML5 Semantik
- CSS3 Modern (CSS Grid, Flexbox, Variable-driven tokens)
- Vanilla JavaScript (ES6+)
- Font: DM Sans & JetBrains Mono
